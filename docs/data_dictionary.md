# Словарь данных

Все файлы — производные от ежемесячных отчётов FHWA *Traffic Volume Trends*
(таблица 5, «Changes on ALL Estimated Roads by Region and State»).

## `data/traffic_vmt_monthly.csv` — факт

| Поле | Тип | Описание |
|---|---|---|
| `month` | date | Первое число месяца отчёта (`2024-01-01` = январь 2024) |
| `state` | text | Штат или округ Колумбия в написании FHWA |
| `region` | text | Регион FHWA: Northeast, South Atlantic, North Central, South Gulf, West |
| `vmt_millions` | decimal | Оценка пробега за месяц, млн миль |
| `stations` | integer | Число пунктов непрерывного учёта, по которым отчитался штат |

Одна строка = один штат × один месяц. 32 месяца × 51 территория = 1 632 строки.

## `data/dim_state.csv` — измерение штатов

| Поле | Тип | Описание |
|---|---|---|
| `state` | text | Штат (ключ) |
| `region` | text | Регион FHWA |

## `data/dim_date.csv` — календарь

| Поле | Тип | Описание |
|---|---|---|
| `date` | date | День календаря |
| `year` | integer | Год |
| `month_number` | integer | Номер месяца 1–12 |
| `month_name` | text | Короткое название месяца (янв, фев, …) |
| `month_label` | text | Подпись оси, например `янв 24`; сортируется по `date` |
| `quarter` | text | Квартал (`Q1`…`Q4`) |

Календарь начинается 2023-01-01 (нужен для сравнения с прошлым годом) и
заканчивается последним месяцем с данными.

## Правила

- Значения VMT не пересчитываются и не сглаживаются: взяты как опубликованы.
- Пропусков в факте нет: если штат не отчитался, строка отсутствует.
- `stations` не суммируется по месяцам как «пункты учёта» — это счётчик
  отчитавшихся постов в конкретном месяце.
